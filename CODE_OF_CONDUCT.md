# Code of Conduct

This project adopts the **[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)** as its code of conduct. It applies to everyone who takes part: in issues, pull requests, discussions, and any events or channels run by the project.

## Reporting

Report conduct concerns privately to the maintainers (see `GOVERNANCE.md`):
- open a **private report** through the repository's *Security → Report a vulnerability* form and title it "Conduct", or
- message a maintainer directly on GitHub.

Reports are kept confidential. Maintainers follow the Covenant's enforcement ladder: correction, warning, temporary suspension, then permanent ban.
